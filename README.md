# さくいん拾い

教科書のPDFと索引用語のExcelを読み込み、Excelの用語がPDFのどのページに出てくるかを探して、ページ番号をExcelに書き込むツールです。

- ファイルは `sakuin-hiroi.html` の1つだけです。ダウンロードしてブラウザで開けば使えます。
- インストールやネット接続は必要ありません。
- PDFとExcelはパソコンの中だけで処理し、外部には送信しません。AI校正を使う場合も、送り先は同じパソコンで動いているAIサーバーだけです。

---

## 動作環境

- **ブラウザ**：Google Chrome または Microsoft Edge の最新版を推奨します。Safari と Firefox では動作を確認していません。
- **PDF**：文字データが入ったPDF（InDesignなどから書き出したもの）が対象です。スキャンした画像だけのPDFは検索できません。
- **Excel**：`.xlsx` 形式のみです。`.xls` の場合は、Excelで `.xlsx` に保存し直してください。

## 基本の流れ

画面は次の3つに分かれています。

- 左：設定パネル
- 右上：結果表
- 右下（または右）：目視確認

上部のバーには、いま何の処理をしているかと、その処理の進み具合が表示されます。バーの右端の「中止」で、次の処理を途中で止められます。

- PDFの読み込み
- 検索
- 文字色の解析
- AI校正
- 前回の状態の復元

### 1. PDFを読み込む

左の「1 PDF」にPDFをドロップします。

- ファイルは画面のどこにドロップしても読み込めます。PDFかExcelかは自動で見分けます。
- PDFとExcelをいっしょにドロップしてもかまいません。PDF→Excelの順に読み込みます。
- 保存していない作業があるときに新しいファイルをドロップすると、読み込む前に確認します。

読み込みが終わると、次の内容を判定して「予想抽出精度」を表示します。

- テキストPDFか、画像PDFか、一部が画像か
- 文字化けの有無
- ルビの検出数

精度が「中」や「低」の場合は、理由の一覧と、取り出した本文の見本を確認してください。

### 2. ノンブルと検索範囲を指定する

- **ノンブルの位置を指定**
  - ページを見開きで表示するので、ノンブルの数字をドラッグで囲みます。
  - 「共通」「左ページ」「右ページ」の切り替えがあります。見開きで位置が違う場合は、左右それぞれに枠を描きます。
  - 「PDFの1枚目」が右ページか左ページかを正しく設定してください。左右の判定に使います。
  - ページ送りは、PDF表示の下にあります。
- **検索範囲を指定**
  - 本文の範囲を囲むと、枠の外（柱など）は検索しません。
- **指定した位置にノンブルが無いページは検索しない**（初期設定でオン）
  - 表紙や扉など、ノンブルのないページを自動で外します。
- **検索するページ**
  - 「1-238」「12-240, 245」のようにページ番号で範囲を入力すると、その範囲だけを検索します。
  - 巻末の索引ページを検索対象から外すときに使います。

### 3. 対象のフォントを選ぶ（必要な場合）

- PDFに入っているフォントを、見本と文字数つきで一覧にします。チェックしたフォントの語だけを確定・申し送りの対象にします。チェックを外したフォントの語は「対象外」になります。
- ボタンで、フォントをまとめて選べます。いまの選択に当てはまるボタンは青く表示されます。
  - すべて
  - 本文以外：本文フォント（一覧で「本文」の札が付いたもの）以外のすべて
  - 本文中の太字：太字のフォントのうち、本文と同じ文字サイズのものだけ。文字サイズの選択も本文サイズに切り替わります。見出しや図の説明文などを除いて、本文中の太字語だけを拾いたいときに使います。
  - ゴシック太字
  - 太字
  - ゴシック
  - 明朝
- 太字かどうかは、フォント名の末尾の太さ（Light、Regular、Medium、DeBold、Bold、W3〜W9 など）から判定しています。
  - 同じ書体がPDFの中で複数の太さで使われている場合は、その書体でいちばん多く使われている太さより太いMedium以上のフォントを「太字」とします。例：UD新ゴのRegularがいちばん多く、Mediumもあれば、Mediumが太字になります。Regular以下は太字になりません。
  - 見出ゴMB31・見出ミンMA31などの見出し用の太い書体も太字とします。
  - DeBold（DB）以上の太さは、同じ書体の他の太さがなくても太字とします。
  - 本文が明朝体の場合、Medium以上のゴシック体は太字とします（明朝の本文の中で、語だけゴシックにして強調している教科書向け）。本文がゴシック体の場合、このルールは使いません。
  - 本文フォントは「いちばん多く使われている文字サイズの中で、いちばん文字数の多いフォント」です。同じ書体・同じ太さのフォント（例：UDReiminPr6N-L と UDReiminPr6-Light）にも「本文」の札が付きます。
  - フォント一覧には太さの札（Medium など）が付きます。「太字」の札にマウスを重ねると、太字と判定した理由が表示されます。
  - 本文がゴシック体で、同じ書体の他の太さが使われていない Medium は太字に入りません。その場合は「本文以外」のボタンも試してください。
  - 明朝体の本文の場合、ゴシック体の見出しや図の説明文も太字に含まれやすくなります。文字サイズで絞り込むか、強調箇所のメニューから書式ごとに対象外にしてください。
- 1語の中で文字ごとにフォントが分かれている場合（合成フォントなど）は、半分以上の文字が対象フォントならその語を対象にします。
- 対象のフォント・文字サイズ・文字色は、検索の後でも変えられます。変えると、PDFを読み直さずに、検索結果の確定・申し送りと対象外をその場で振り分け直します。PDFを見ながら設定を調整できます。
- 文字サイズでも絞り込めます。
- 「文字色を解析」を押すと、文字色でも絞り込めます。
  - 全ページを描画して調べるため時間がかかります（250ページで1〜2分程度）。
  - 途中で「解析を中止」を押せば止められます。

### 4. 索引用語のExcelを読み込む

左の「4 索引用語のExcel」にExcelをドロップし、列を確認します。

| 項目 | 初期値 | 内容 |
|---|---|---|
| 用語の列 | B列 | 検索する用語 |
| 確定ページ | C列 | 索引に載せるページ |
| 申し送りページ | D列 | 要確認として申し送るページ |
| 備考 | E列 | 理由などの文章 |
| 対象外ページ | F列 | 検索で見つかったが対象から外したページ |

- 1行目が見出しの場合、「開始行」は自動で2になります。
- 「（書き込まない）」を選んだ列には書き込みません。
- 用語の列と同じ列を確定ページなどに指定すると、警告が出て保存できなくなります。用語を上書きしてしまうのを防ぐためです。
- 用語の括弧の中は除いて検索します。例：「ルター（マルティン）」は「ルター」で検索します。

### 5. 検索の設定をして実行する

- **複合語**（「奴隷」に対する「黒人奴隷」など）の扱いを選びます。
  - 「申し送りにする」（初期値）：そのページを申し送りに回し、備考に記録します。
  - 「ページに含める」：確定ページに含め、備考にその旨を記録します。
- **ルビを除いて検索する**（初期設定でオン）：本文にルビが混ざって検索できなくなるのを防ぎます。
- 「検索して転記」を押します。

### 6. 目視確認する

- 結果表の用語をクリックすると、右側にPDFの該当ページを表示し、拾った箇所を強調します。強調枠はアニメーションで目立たせます。
- 強調の色（初期値）は次のとおりです。パネル上部の色見本を押すと変えられ、「色を戻す」で初期値に戻ります。
  - 確定：赤
  - 申し送り：青
  - 対象外：緑
- 「単ページ／見開き」で表示を切り替えられます。「－」「全体」「＋」で拡大・縮小できます。
- **強調箇所をクリックしたときのメニュー**
  - 「このページを」確定にする／申し送りにする／対象外にする
  - 「このフォントを」検索対象のフォントに加える（対象フォント外で対象外になっている語のとき）
  - 「この書式（フォント・サイズ・色）を」この用語だけ対象外にする／すべての用語で対象外にする
  - メニューには、その語のフォント名とサイズが表示されます。1語の中でフォントが分かれているときは、「フォントの内訳」も表示されます。
  - 例：青文字の太字に出てくる箇所をまとめて対象外にしたいときは、その箇所をクリックして「すべての用語で対象外にする」を選びます。
- 画面下の「確定／申し送り／対象外」ボタンでも、表示中のページの扱いを切り替えられます。
- **好きなページを開く**：「ページ」にノンブルを入れて「移動」（またはEnter）を押すと、そのページを表示します。
  - PDFの何枚目かで開くときは「#12」のように入力します。
  - 「‹ 前のページ」「次のページ ›」で、PDFの順に1ページ（見開きでは2ページ）ずつめくれます。
  - 「◀」「▶」は、選択中の用語が見つかったページだけを順にたどります。
  - 用語を選んでいなくても、PDFを読み込めばページを表示できます。
- **自分でページを追加する**：検索で拾われなかったページを、選択中の用語の確定ページに追加できます。
  1. 結果表で用語を選び、追加したいページを開きます。
  2. 「文字をドラッグして追加」を押し、ページ上の該当する文字をドラッグで囲みます。
  3. そのページが確定ページに入り、囲んだ文字が二重線の枠で表示されます。備考には「目視確認で追加：p.88（本文の「黒人奴隷」）。」と記録します。
  4. 終わったら「文字をドラッグして追加」をもう一度押します（Escキーでも終われます）。
  - 囲んだ文字に用語が含まれていないときは、上部の表示で知らせます（追加はします）。
  - 取り消すときは、追加した枠をクリックして「この追加を取り消す」を選びます。
  - ノンブルのないページは追加できません。
  - 追加したページは保存時に記録され、作業の再開で復元できます。
- 結果表の「対象フォント」列で、用語ごとに検索するフォントを変えられます。

### 7. Excelに保存する

「結果をExcelで保存」を押すと、`元のファイル名_さくいん.xlsx` を保存します。

- 確定・申し送り・対象外のページと備考を、指定した列に書き込みます。
- 備考の列に元々書かれている内容は残し、その後ろに追記します。
- 「保存時に見出し行を書き込む」（初期設定でオン）がオンのときは、見出しを書き込みます。
  - 元のシートに見出し行がある場合は、その行を書き換えます。
  - 見出し行がない場合は、1行目に見出しを挿入します。

## 備考の書き方の例

```
黒人奴隷という用語も「奴隷」のさくいんに拾うべきか要確認。
今回は拾わなかったが、拾う場合、p.88追加。
対象外：p.17（検索ページ外）
対象外：p.15（書式「NotoSansCJKjp-Black・11.0pt・#0066cc」で対象外）
p.31は目視確認で外した。拾う場合、p.31追加。
p.88はリスト記載のページ（PDF内で該当箇所を確認できず）。要確認。
```

対象外の理由には、次のものがあります。

- 検索ページ外
- 検索範囲外
- 対象フォント外
- 対象サイズ外
- 対象色外
- 書式で対象外
- 目視確認で対象外
- AI校正で対象外
- リストの記載に従い対象外

## 作業の再開（前回の状態を復元する）

保存したExcelには、「さくいん拾い_設定」というシートが追加されます。

- シートの上半分には、作業の設定を一覧で表示します。
  - 列の割り当て
  - ノンブル・検索範囲の位置、検索するページ
  - フォント・サイズ・色の選択
  - 書式で対象外にしたもの、用語ごとの設定
  - 集計
- シートの下には、作業の再開に使う「復元用データ」が入っています。このデータは編集しないでください。
- 設定を変えたいときは、アプリで変更してから保存し直してください。このシートを書き換えても、アプリには反映されません。
- お客さんに提出するときに不要であれば、このシートを削除してかまいません。ただし削除したファイルからは作業を再開できなくなるので、手元に削除前のファイルを残しておいてください。
- 以前の版で保存した、隠しシート（`_sakuin_state`）付きのExcelも読み込めます。保存し直すと、隠しシートは「さくいん拾い_設定」シートに置き換わります。

**再開の手順**

1. PDFを読み込みます。
2. 前回保存したExcelを読み込みます。
3. 「前回の作業状態が含まれています」と表示されたら、「前回の作業状態を復元」を押します。

次の内容が保存時の状態に戻ります。

- ノンブル・検索範囲の枠
- 検索するページ
- フォント・サイズ・色の選択
- 用語ごとのフォント
- 確定／申し送り／対象外の変更
- 書式での除外
- AIの判定

**注意点**

- 前回とページ数や内容が違うPDFを読み込むと、警告が出ます。復元はできますが、結果がずれることがあります。
- 文字色で絞り込んでいた場合は、復元のときに色の解析をやり直すため時間がかかります。
- 再保存しても、備考の自動記入は二重に追記されません。

## リストの照合（機械的な校正）

Excelのリストに書かれているページと、アプリの検索結果を突き合わせて、違いを表示します。照合は表示するだけで、検索結果は変わりません。

- Excelの確定・申し送り・対象外の列にページが書かれていると、「リストに書かれているページと照合する」が自動でオンになります。
- ページが1つも書かれていない作業前のリストでは、照合のスイッチは押せません。
- 結果表の「照合」列に、違いを種類ごとの件数で表示します。「照合で差分」で、違いのある用語だけに絞り込めます。
  - 一致
  - リストのみ：リストでは拾っているが、アプリでは拾っていないページ
  - アプリのみ：アプリでは拾っているが、リストには無いページ
  - 扱い違い：申し送り・対象外の扱いが違うページ
- 用語を開くと、目視確認の上部に違いを一覧で表示します。表示例は次のとおりです。
  - 「リストでは拾っているが、アプリでは拾っていない：p.14（リスト：確定／アプリ：申し送り）、p.88（リスト：確定／アプリ：PDFで見つからず）」
  - 「アプリでは拾っているが、リストには無い：p.17（リスト：記載なし／アプリ：確定）」
- ページ一覧では、違いのあるページに「≠」の印を付けます。リストにあってPDFで見つからないページは「PDFなし」として並べます。
- 強調箇所をクリックすると、メニューに「リストでの扱い」も表示します。
- 用語ごとの「この用語をリストの内容に合わせる」を押したときだけ、その用語の結果をリストに合わせます。このボタンは、その用語のリストにページが書かれている場合にだけ表示されます。まとめて合わせる機能はありません。

**使いどころ**

- お客さんが手直ししたリストの確認：そのExcelを読み込んで復元すると、手直しされた箇所が違いとして出ます。
- 手作業で作った既存リストの機械的な校正：「さくいん拾い_設定」シートがないExcelでも、ノンブルを設定して検索すれば照合できます。

## 校正（完成済みリストが本文を網羅できているかの確認）

完成済みのリストが、本文PDFの語を正しく網羅できているかを機械的に確かめます。リストの形式は、このアプリが出力するExcelの形式が基準です。

| 項目 | 列（初期値） |
|---|---|
| 用語 | B列 |
| 確定ページ | C列 |
| 申し送りページ | D列 |
| 対象外ページ | F列 |
| 備考 | E列 |

**手順**

1. 本文PDFを読み込み、ノンブルの位置を指定します。必要に応じて、検索範囲・検索するページ・対象フォントも設定します。
   - リストに「さくいん拾い_設定」シートがある場合は、先に「前回の作業状態を復元」を押すと、リストを作ったときと同じ設定で校正できます。
2. 完成済みのリストを読み込みます。
3. Excelの欄の「校正（リストの網羅を確認）」を押します。
   - いまの設定で検索し、リストと突き合わせます。
   - 結果表は、指摘のある用語に絞り込まれます。
   - 用語を開くと、目視確認で違いを確かめられます。
4. 「校正結果をExcelで保存」を押すと、リストに「校正結果」シートを追加したファイル（`元のファイル名_校正結果.xlsx`）を保存します。リストの確定・申し送り・対象外・備考の列は変更しません。

**指摘の種類**

| 指摘 | 意味 |
|---|---|
| 漏れの可能性 | PDFで見つかり、アプリでは確定になったが、リストには確定として書かれていないページ |
| 誤りの可能性 | リストには確定として書かれているが、アプリでは拾っていない、またはPDFで見つからないページ |
| 扱い違い | 申し送り・対象外の扱いが、リストとアプリで違うページ |

「校正結果」シートには、指摘ごとに次の内容を一覧にします。上部には、校正日時・PDF・検索の設定・指摘の件数も記録します。

- 行
- 用語
- ページ
- 指摘の種類
- リストでの扱い
- アプリでの扱い
- 前後の文、または対象外の理由

## AI校正（ローカルLLM、任意）

パソコンで動くAI（LM Studio、Ollama、llama.cpp、KoboldCpp、Jan など、OpenAI互換のサーバー）に、各ページの前後の文を読ませて、索引に載せるべきかを判定させます。

**準備**

- **LM Studio**：「Developer」でサーバーを起動し、「Enable CORS」をオンにします。
- **Ollama**：環境変数 `OLLAMA_ORIGINS` に `*` を設定して、Ollamaを起動し直します。

**使い方**

1. 左の「6 AI校正」で「自動で探す」を押し、モデルを選びます。
2. 「要確認の用語を確認」または「すべての用語を確認」を押します。
3. アプリの判定とAIの判定が違う箇所は、提案として表示されます。
   - 結果表の「AI」列
   - 目視確認のページ一覧の「AI」の印
   - 判定理由の欄
4. 提案は「AIの提案を反映」を押すまで、結果には反映されません。

**指示を出してAIに振り分けを任せる**

教科書の作り方は本ごとに違うため、アプリの判定だけでは決めきれない場合があります。そのときは、指示を書いてAIに振り分けを任せます。指示の種類は2つです。

| 種類 | 使う場面 | AIの動き |
|---|---|---|
| ざっくり指示（初期値） | 担当者が思いついたことを一言で頼む | 指示の意図をくみ取り、索引づくりの常識で補って判断します。指示が触れていないページは、いまの判定のまま変えません。 |
| 先方のルール | 出版社からの指示文をそのまま使う | 指示に厳密に従います。指示から判断できないページは「申し送り」にします。 |

1. 検索してから、「AIへの指示」で種類を選び、指示を書きます。
   - ざっくり指示の例：「見出しや図の説明文で出てくるのは外して」「太字のところだけ拾って、あとは申し送り」。入力欄の下の例を押すと、その文が入力欄に追加されます。
   - 先方のルールの例：「本文中の太字の語だけを拾う。見出し・図表の説明文・側注での出現は対象外。」
2. 「対象」を選びます：すべての用語／要確認の用語だけ／選択中の用語だけ。
3. 「AIに振り分けを任せる」を押します。
3. AIは、各ページの用例に次の書式情報を合わせて読み、指示に照らして「確定」「申し送り」「対象外」に振り分けます。
   - 前後の文
   - フォント名、ゴシック／明朝、太字かどうか
   - 文字サイズ（本文より大きい・同じ・小さい）
   - 色（文字色を解析した場合）
   - 複合語かどうか
4. 結果は「AIの提案」と違い、その場で反映されます。判定が変わったページは、備考に理由が記録されます。
   - 先方のルールの例：「p.15は先方指示に基づきAIが要確認と判定（側注での出現）。拾う場合、p.15追加。」「対象外：p.12（先方指示に基づきAIが対象外と判定：見出しでの出現）」
   - ざっくり指示の例：「p.15はAIが要確認と判定（側注での出現）。拾う場合、p.15追加。」

**振り分けの注意点**

- 目視確認で手動で決めたページと、自分で追加したページは、AIの判定で上書きしません。
- 指示文と指示の種類は、保存時の「さくいん拾い_設定」シートに記録され、復元できます。
- 先方のルールでは、指示から判断できないページは「申し送り」になります。
- 結果表の「AI」列には「指示で3件」（判定が変わったページ数）または「指示どおり」と表示されます。

**注意点**

- 1回の問い合わせに180秒以上かかった場合は、その用語をエラーとして次の用語に進みます。
- 判定の精度はモデルによって大きく変わります。小さなモデルでは、回答の形式が崩れてエラーになることがあります。

## パネルの切り離し

「設定」「結果」「目視確認」の各パネルの見出しにある「別ウィンドウ」を押すと、そのパネルを独立したウィンドウに表示できます。

- ウィンドウを閉じるか「ここに戻す」を押すと、元の位置に戻ります。
- パネルの境目はドラッグで幅を変えられます。ダブルクリックで元の幅に戻ります。

**注意点**

- ブラウザがポップアップをブロックしている場合は、このファイルのポップアップを許可してください。
- 設定パネルを別ウィンドウにしているとき、ノンブル・検索範囲の指定画面は元のウィンドウ側に開きます。
- 別ウィンドウに移した設定パネルでは、フォント一覧の見本がPDFの書体ではなく通常の書体で表示されます。

## 知っておいてほしいこと（検索の仕組みと限界）

- 改行や行の折り返しはつなげて検索します。行をまたいだ語も見つかります。
- 全角／半角の英数字、半角カナは同じ文字として扱います。
- 部首用の文字コードで書き出された漢字（「⻄」など）は、通常の漢字に直して検索します。
- 表記ゆれは自動では吸収しません。漢字とかな、旧字体、送り仮名の違いなどです。「見つからず」になった語は表記を確認してください。
- 図版の中の文字（画像）や、アウトライン化された文字は検索できません。
- 縦書きの本でも検索とノンブルの読み取りはできますが、強調枠の位置は横組みほど正確ではありません。
- 複合語の判定は「前後に漢字（カタカナの語ならカタカナ）が続くか」で行っています。同じ見出し語を含む長い語が別の索引用語として載っている場合は、申し送りに回しません（例：「黒人奴隷」も用語にある場合）。

## 困ったとき

| 症状 | 確認すること |
|---|---|
| 予想抽出精度が「低」、または見本の文字が化けている | PDFの書き出し設定（フォントの埋め込み・文字情報）を確認し、PDFを書き出し直してください。 |
| ノンブルが読み取れない、番号がずれる | 枠がノンブルの数字だけを囲んでいるか、「PDFの1枚目」の左右の設定が正しいかを確認してください。 |
| 「ノンブルが1ページも読み取れていません」と出る | 枠の位置が数字から外れています。位置を指定し直してください。 |
| 柱の語が全ページで拾われる | 「検索範囲を指定」で本文だけを囲んでください。 |
| 索引ページの語が拾われる | 「検索するページ」で本文の範囲だけを指定してください。 |
| 「検索中に設定が変わったため、検索を中止しました」と出る | 検索中に設定を変えると、結果の取り違えを防ぐために検索を中止します。もう一度「検索して転記」を押してください。 |
| 太字のはずの語が対象外になる | 強調箇所をクリックし、メニューに表示されるフォント名と対象外の理由を確認してください。「検索対象のフォントに加える」で、その場で対象にできます。名前にBoldが付かないフォントの場合は、「本文以外」のボタンも試してください。 |
| 同じファイルを読み込み直したい | そのままもう一度選ぶかドロップすれば、読み込み直します。 |
| ドロップしても読み込まれない | 処理中（上部のバーが動いている間）は読み込みません。終わってからドロップしてください。PDFとExcel（.xlsx）以外のファイルは読み込めません。 |
| 検索で拾われないページを索引に入れたい | 目視確認でそのページを開き、「文字をドラッグして追加」で本文の文字を囲んでください。 |
| 保存ボタンが押せない | 列の指定が重複していないか、用語の列と同じ列を指定していないかを確認してください。 |
| 別ウィンドウが開かない | ブラウザのポップアップの許可を確認してください。 |
| AIに接続できない | AIサーバーの起動、CORSの設定、サーバーURLを確認してください。 |

## 保存される設定

次の設定はブラウザに記憶され、次に開いたときもそのまま使えます。

- パネルの幅
- 目視確認の単ページ／見開き
- 強調の色
- AIサーバーのURLとモデル
- AIへの指示と、指示の種類

保存していない作業があるときにブラウザのタブやウィンドウを閉じようとすると、本当に閉じてよいか確認します。作業中の処理（読み込み・検索・AIなど）があるときも同じです。

ブラウザのサイトデータを消去すると、初期設定に戻ります。
