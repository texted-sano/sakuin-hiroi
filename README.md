# さくいん拾い

教科書のPDFと索引用語のExcelを読み込み、Excelの用語がPDFのどのページに出てくるかを探して、ページ番号をExcelに書き込むツールです。

- ファイルは `sakuin-hiroi.html` の1つだけです。ダウンロードしてブラウザで開けば使えます。
- インストールやネット接続は必要ありません。
- PDFとExcelはパソコンの中だけで処理し、外部には送信しません。AI校正を使う場合も、送り先は同じパソコンで動いているAIサーバーだけです。

---

## 動作環境

- **ブラウザ**：Google Chrome または Microsoft Edge の最新版を推奨します。Safari と Firefox では動作を確認していません。
- **PDF**：文字データが入ったPDF（InDesignなどから書き出したもの）が対象です。スキャンした画像だけのPDFは検索できません。
- **Excel**：`.xlsx` 形式のみです。`.xls` の場合は、Excelで `.xlsx` に保存し直してください。

## 基本の流れ

画面は次の3つに分かれています。

- 左：設定パネル
- 右上：結果表
- 右下（または右）：目視確認

結果の表の上の「用語を検索」に語を入れると、その用語までジャンプしてPDFの該当ページを開きます。Enterで次の候補、Shift+Enterで前の候補に移ります。ひらがな・カタカナの違いは区別しません。結果の表の列の見出しをクリックすると、その列を細く折りたためます（もう一度クリックで元に戻ります。折りたたんだ状態は次回も引き継ぎます）。

画面右上の「使い方」を押すと、操作の説明を大きく表示します。初めて使うときは、まずそちらを上から順に読んでください。

上部のバーには、いま何の処理をしているかと、その処理の進み具合が表示されます。バーの右端の「中止」で、次の処理を途中で止められます。

- PDFの読み込み
- 検索
- 文字色の解析
- AI校正
- 前回の作業状態の復元

### 1. PDFを読み込む

左の「1 PDF」にPDFをドロップします。

- ファイルは画面のどこにドロップしても読み込めます。PDFかExcelかは自動で見分けます。
- PDFとExcelをいっしょにドロップしてもかまいません。PDF→Excelの順に読み込みます。
- 保存していない作業があるときに新しいファイルをドロップすると、読み込む前に確認します。

読み込みが終わると、次の内容を判定して「予想抽出精度」を表示します。

- テキストPDFか、画像PDFか、一部が画像か
- 文字化けの有無
- ルビの検出数

精度が「中」や「低」の場合は、理由の一覧と、取り出した本文の見本を確認してください。

### 2. ノンブルと検索範囲を指定する

- **ノンブルの位置を指定**
  - ページを見開きで表示するので、ノンブルの数字をドラッグで囲みます。
  - 「共通」「左ページ」「右ページ」の切り替えがあります。見開きで位置が違う場合は、左右それぞれに枠を描きます。
  - 「PDFの1枚目」が右ページか左ページかを正しく設定してください。左右の判定に使います。
  - ページ送りは、PDF表示の下にあります。
  - 「巻頭3」「巻末5」のように文字の付いたノンブルも、そのまま読み取ります。対応している文字は「巻頭」「口絵」「巻末」「付録」です。
  - Excelには「巻頭3, 巻頭4, 12, 13, 巻末5」の順（巻頭・口絵 → 本文 → 巻末・付録）で書き込みます。連続ページをまとめる設定では「巻頭3-4」のようにまとめます。
- **検索範囲を指定**
  - 本文の範囲を囲むと、枠の外（柱など）は検索しません。
- **指定した位置にノンブルが無いページは検索しない**（初期設定でオン）
  - 表紙や扉など、ノンブルのないページを自動で外します。
- **検索するページ**
  - 「1-238」「12-240, 245」のようにページ番号で範囲を入力すると、その範囲だけを検索します。
  - 巻末の索引ページを検索対象から外すときに使います。
  - 巻頭・巻末のページは「巻頭1-8, 1-238, 巻末1-4」のように書けます。範囲に「巻頭」「巻末」を書かなかった場合、そのページは絞り込まずにすべて検索します。

### 3. 対象のフォントを選ぶ（必要な場合）

- PDFに入っているフォントを、見本と文字数つきで一覧にします。チェックしたフォントの語だけを確定・申し送りの対象にします。チェックを外したフォントの語は「対象外」になります。
- ボタンで、フォントをまとめて選べます。いまの選択に当てはまるボタンは青く表示されます。
  - すべて
  - 本文以外：本文フォント（一覧で「本文」の札が付いたもの）以外のすべて
  - 本文中の太字：太字のフォントのうち、本文と同じ文字サイズのものだけ。文字サイズの選択も本文サイズに切り替わります。見出しや図の説明文などを除いて、本文中の太字語だけを拾いたいときに使います。
  - ゴシック太字
  - 太字
  - ゴシック
  - 明朝
- 太字かどうかは、フォント名の末尾の太さ（Light、Regular、Medium、DeBold、Bold、W3〜W9 など）から判定しています。
  - 同じ書体がPDFの中で複数の太さで使われている場合は、その書体でいちばん多く使われている太さより太いMedium以上のフォントを「太字」とします。例：UD新ゴのRegularがいちばん多く、Mediumもあれば、Mediumが太字になります。Regular以下は太字になりません。
  - 見出ゴMB31・見出ミンMA31などの見出し用の太い書体も太字とします。
  - DeBold（DB）以上の太さは、同じ書体の他の太さがなくても太字とします。
  - 本文が明朝体の場合、Medium以上のゴシック体は太字とします（明朝の本文の中で、語だけゴシックにして強調している教科書向け）。本文がゴシック体の場合、このルールは使いません。
  - 本文フォントは「いちばん多く使われている文字サイズの中で、いちばん文字数の多いフォント」です。同じ書体・同じ太さのフォント（例：UDReiminPr6N-L と UDReiminPr6-Light）にも「本文」の札が付きます。
  - フォント一覧には太さの札（Medium など）が付きます。「太字」の札にマウスを重ねると、太字と判定した理由が表示されます。
  - 本文がゴシック体で、同じ書体の他の太さが使われていない Medium は太字に入りません。その場合は「本文以外」のボタンも試してください。
  - 明朝体の本文の場合、ゴシック体の見出しや図の説明文も太字に含まれやすくなります。文字サイズで絞り込むか、強調箇所のメニューから書式ごとに対象外にしてください。
- 1語の中で文字ごとにフォントが分かれている場合（合成フォントなど）は、半分以上の文字が対象フォントならその語を対象にします。
- 対象のフォント・文字サイズ・文字色は、検索の後でも変えられます。変えると、PDFを読み直さずに、検索結果の確定・申し送りと対象外をその場で振り分け直します。PDFを見ながら設定を調整できます。
- 文字サイズでも絞り込めます。
- 「文字色を解析」を押すと、文字色でも絞り込めます。
  - 全ページを描画して調べるため時間がかかります（250ページで1〜2分程度）。
  - 途中で「解析を中止」を押せば止められます。

### 4. 索引用語のExcelを読み込む

左の「4 索引用語のExcel」にExcelをドロップし、列を確認します。

| 項目 | 初期値 | 内容 |
|---|---|---|
| 用語の列 | B列 | 検索する用語 |
| 確定ページ | C列 | 索引に載せるページ |
| 申し送りページ | D列 | 要確認として申し送るページ |
| 備考 | E列 | 理由などの文章 |
| 対象外ページ | F列 | 検索で見つかったが対象から外したページ |
| 保留 | G列 | リストを基準にしたときの、検索結果との過不足（振り分け待ち） |
| 訂正箇所 | H列 | 読み込んだリストから何をどう直したか |
| 対象外の理由 | I列 | 対象外にしたページと、その理由（書式・範囲外など） |

- 1行目が見出しの場合、「開始行」は自動で2になります。
- 「（書き込まない）」を選んだ列には書き込みません。
- 用語の列と同じ列を確定ページなどに指定すると、警告が出て保存できなくなります。用語を上書きしてしまうのを防ぐためです。
- 用語の括弧の中は除いて検索します。例：「ルター（マルティン）」は「ルター」で検索します。

**結果の表を直接書き換える（手修正）**

結果の表のセルをダブルクリックすると、その場で書き換えられます。Enterで決定、Escでやめます（改行はShift+Enter）。

| 列 | 書き換えたときの動き |
|---|---|
| 用語 | 直した用語でPDFを検索し直します。下の「検索除外ワード」で、外したい語も指定できます |
| 確定ページ・申し送り・対象外 | 書いたページの扱いを変えます。確定・申し送りの列から消したページは対象外になります。対象外の列から消したページは、アプリの判定に戻ります。PDFにないページ番号も書けます |
| 備考 | 1行ずつ覚えます。自動で書いた行を直すと、その行だけ直した文章になります。行を消すと、その行は出なくなります。新しく足した行は、そのまま残ります |
| 対象外の理由・訂正箇所 | 書いた文章をそのまま使います（自動の書き込みより優先） |

- 備考の手修正は、もとになった事項と結び付けて覚えています。たとえば「奴隷制という用語も…要確認。拾う場合、p.16追加。」の行を直したあと、p.16を対象外にすると、直した行も備考から消えます（申し送りに戻すと、直した文章で再び出ます）。もとの事項のページが変わった場合は、自動の文章に戻ります。
- **検索除外ワード**：用語のセルをダブルクリックすると、用語の下に「検索除外ワード」の欄が出ます。「インド洋、東インド会社」のように「、」で区切って入れると、その語に当たる箇所を「インド」の検索から外し、対象外（理由：除外ワード「インド洋」に一致）にします。括弧内の語（例：「東インド会社（イギリス）」の「イギリス」）を入れると、その語での検索もしません。指定した語は用語の下に「除外：～」と表示し、設定シートの「用語ごとの設定」にも記録します。
- 書き換えたセルには「手」の印が付きます。保存したExcelでは、そのセルを薄いオレンジで塗ります。設定シートにも手修正したセルの数を記録します。
- 書き換えたセルをもう一度ダブルクリックして「自動の内容に戻す」を押すと、アプリの判定・自動の文章に戻ります。
- 手修正の内容と印は、作業を再開しても引き継ぎます。

**用語を直す・追加する**

検索のあとで、リストの用語の表記を直したり、用語を追加したりできます。

- 直す：結果表で用語を選び、目視確認の用語名の横の「用語を直す」を押します。直した用語でPDFを検索し直します。
- 追加：結果表の上の「＋ 用語を追加」を押します。リストの最後の行に追加して、PDFを検索します。
- 同じ用語がすでにリストにあるときは追加できません。
- 直した内容は「訂正箇所」の列に記録します。例：「用語「大西洋」→「西洋」」「用語を追加」

### 5. 検索の設定をして実行する

- **複合語**（「奴隷」に対する「黒人奴隷」など）の扱いを選びます。
  - 「申し送りにする」（初期値）：そのページを申し送りに回し、備考に記録します。
  - 「ページに含める」：確定ページに含め、備考にその旨を記録します。
- **ルビを除いて検索する**（初期設定でオン）：本文にルビが混ざって検索できなくなるのを防ぎます。
- 「検索して転記」を押します。

### 6. 目視確認する

- 結果表の用語をクリックすると、右側にPDFの該当ページを表示し、拾った箇所を強調します。強調枠はアニメーションで目立たせます。
- 強調の色（初期値）は次のとおりです。パネル上部の色見本を押すと変えられ、「色を戻す」で初期値に戻ります。
  - 確定：赤
  - 申し送り：青
  - 対象外：緑
  - 保留：オレンジ（突合せ確認のとき）
- 「単ページ／見開き」で表示を切り替えられます。「－」「全体」「＋」で拡大・縮小できます。
- **強調箇所をクリックしたときのメニュー**
  - 「このページを」確定にする／申し送りにする／対象外にする
  - 「このフォントを」検索対象のフォントに加える（対象フォント外で対象外になっている語のとき）
  - 「この書式（フォント・サイズ・色）を」この用語だけ対象外にする／すべての用語で対象外にする
  - メニューには、その語のフォント名とサイズが表示されます。1語の中でフォントが分かれているときは、「フォントの内訳」も表示されます。
  - 例：青文字の太字に出てくる箇所をまとめて対象外にしたいときは、その箇所をクリックして「すべての用語で対象外にする」を選びます。
- 画面下の「確定／申し送り／対象外」ボタンでも、表示中のページの扱いを切り替えられます。
- **好きなページを開く**：「ページ」にノンブルを入れて「移動」（またはEnter）を押すと、そのページを表示します。
  - PDFの何枚目かで開くときは「#12」のように入力します。
  - 「ページ」欄は「次のページ ›」の右にあります。
  - 「‹ 前のページ」「次のページ ›」で、PDFの順に1ページ（見開きでは2ページ）ずつめくれます。
  - 「◀」「▶」は、選択中の用語が見つかったページだけを順にたどります。
  - 用語を選んでいなくても、PDFを読み込めばページを表示できます。
- **自分でページを追加する**：検索で拾われなかったページを、選択中の用語の確定ページに追加できます。
  1. 結果表で用語を選び、追加したいページを開きます。
  2. 「文字をドラッグして追加」を押し、ページ上の該当する文字をドラッグで囲みます。
  3. そのページが確定ページに入り、囲んだ文字が二重線の枠で表示されます。備考には「目視確認で追加：p.88（本文の「黒人奴隷」）。」と記録します。
  4. 終わったら「文字をドラッグして追加」をもう一度押します（Escキーでも終われます）。
  - 囲んだ文字に用語が含まれていないときは、上部の表示で知らせます（追加はします）。
  - 取り消すときは、追加した枠をクリックして「この追加を取り消す」を選びます。
  - ノンブルのないページは追加できません。
  - 追加したページは保存時に記録され、作業の再開で復元できます。
- 結果表の「対象フォント」列で、用語ごとに検索するフォントを変えられます。

### 7. Excelに保存する

「結果をExcelで保存」を押すと、`元のファイル名_さくいん.xlsx` を保存します。

- 確定・申し送り・対象外のページと備考、保留、訂正箇所を、指定した列に書き込みます。
- 「用語を直す」「用語を追加」をした行は、用語の列も書き換えます。
- 備考の列に元々書かれている内容は残し、その後ろに追記します。
- 「保存時に見出し行を書き込む」（初期設定でオン）がオンのときは、見出しを書き込みます。
  - 元のシートに見出し行がある場合は、その行を書き換えます。
  - 見出し行がない場合は、1行目に見出しを挿入します。

### 8. 枠付きPDFを保存する（Excelとセットで納品する場合）

「枠付きPDFを保存」を押すと、拾った箇所に枠を付けたPDF（`元のファイル名_さくいん枠.pdf`）を保存します。

- 枠はPDFの**注釈（四角形のコメント）**として入ります。Acrobatなどで1つずつ移動・削除でき、コメントの一覧で確認できます。
- 各枠のコメントには、用語・ページ・扱いが入ります。例：「「奴隷」p.14　申し送り／複合語「黒人奴隷」の一部」
- 左の「7 枠付きPDFの出力」で、枠を付けるもの（確定／申し送り／対象外）を選べます。初期値は確定と申し送りです。
- 枠の色は目視確認の強調の色と同じです。申し送りは破線、対象外は点線になります。
- 元のPDFは変更しません。本文や書式はそのままで、注釈が加わるだけです。
- パスワードや保護のかかったPDFには書き込めません。

## 備考の書き方の例

備考（E列）には、お客さんに確認したい事項だけを、**1件1行**で書きます（セルの中で改行して並べます）。

```
黒人奴隷という用語も「奴隷」のさくいんに拾うべきか要確認。拾う場合、p.88追加。
奴隷制という用語も「奴隷」のさくいんに拾うべきか要確認。拾う場合、p.16追加。
p.31は目視確認で外した。拾う場合、p.31追加。
```

対象外にした理由は、備考とは別の「対象外の理由」（I列）に書きます。

```
p.17　検索ページ外
p.9, 67, 87　対象フォント外：UDShinGoPr6-Light
p.15　書式「NotoSansCJKjp-Black・11.0pt・#0066cc」で対象外
PDF 23枚目　ノンブルがないページのため対象外（索引から参照できない）
```

対象外の理由には、次のものがあります。

- 検索ページ外
- 検索範囲外
- 対象フォント外
- 対象サイズ外
- 対象色外
- 書式で対象外
- 目視確認で対象外
- AI校正で対象外
- リストの記載に従い対象外

「さくいん拾い_設定」シートの「対象にした書式」には、選んだ絞り込み（「本文中の太字」など）と、対象にしたフォント・文字サイズ・文字色を一覧で記録します。「対象外にした書式」には、対象外にしたフォント・文字サイズ・文字色・書式と、理由ごとの件数（何語・何ページ、どの用語か）をまとめて記録します。

**拾い漏れを防ぐために**

- 指定した位置にノンブルがないページ（章扉・全面の図など）は、索引から参照できないため対象外です。ただし、そのページにも用語が出てくる場合は、黙って外さず「対象外の理由」の列に「PDF ○枚目　ノンブルがないページのため対象外」と書き残します。
- 対象外にしたページも、すべて「対象外ページ」の列と「対象外の理由」の列に残します。黙って消えるページはありません。

## 作業の再開（続きから編集する）

保存したExcelには、「さくいん拾い_設定」というシートが追加されます。

- シートの上半分には、作業の設定を一覧で表示します。
  - 列の割り当て
  - ノンブル・検索範囲の位置、検索するページ
  - フォント・サイズ・色の選択
  - 書式で対象外にしたもの、用語ごとの設定
  - 集計
- シートの下には、作業の再開に使う「復元用データ」が入っています。このデータは編集しないでください。
- 設定を変えたいときは、アプリで変更してから保存し直してください。このシートを書き換えても、アプリには反映されません。
- お客さんに提出するときに不要であれば、このシートを削除してかまいません。ただし削除したファイルからは、設定（ノンブルの位置など）を引き継げなくなります。手元に削除前のファイルを残しておいてください。
- 以前の版で保存した、隠しシート（`_sakuin_state`）付きのExcelも読み込めます。保存し直すと、隠しシートは「さくいん拾い_設定」シートに置き換わります。

**再開の手順**

前回のPDFと、前回保存したExcelを読み込むだけです（同時にドロップしてもかまいません）。ボタンを押さなくても、読み込んだ時点で前回の続きの状態になります。

- ノンブル・検索範囲・フォントなどの設定は「さくいん拾い_設定」シートから戻します。
- 確定・申し送り・対象外・保留のページは、**Excelのリストに書かれている内容をそのまま反映**します。保存したあとにExcelを手で直していれば、直した内容から続きを始めます。
- 目視確認で手動で決めた理由（備考）やドラッグで追加した箇所は、リストの内容と食い違っていなければ引き継ぎます。

**注意点**

- 前回とページ数や内容が違うPDFを読み込むと、自動では復元せず警告を出します。そのPDFで続けるときは「このPDFで作業状態を復元」を押してください。結果がずれることがあります。
- 文字色で絞り込んでいた場合は、復元のときに色の解析をやり直すため時間がかかります。
- 再保存しても、備考の自動記入は二重に追記されません。

## 突合せ確認（既存のリストを基準に、PDFとの過不足を確かめる）

先にExcelのリストがあり（手作業で作ったリストや、お客さんが手直ししたリストなど）、それをPDFと突き合わせて確認するときの使い方です。リストには間違いがあるかもしれないので、**リストを基準にし、検索結果との過不足を別の列に分けて**転記します。リストの確定・申し送り・対象外の列は、自分で振り分けるまで変えません（うっかりリストを壊さないため）。

**手順**

1. PDFとリストを読み込みます。確定・申し送り・対象外の列にページが書かれていると、「リストを基準に突き合わせる（突合せ確認）」が自動でオンになります。
2. ノンブルの位置などを指定して、「検索して転記」を押します（「さくいん拾い_設定」シートがあるリストなら、読み込んだ時点で自動で始まります）。
3. リストと検索結果に過不足があったページは「保留」になります。結果表の「保留」列に件数を、判定に「保留あり」を表示します。
4. 保留のページを、確定・申し送り・対象外に振り分けます。
   - まとめて：左の「保留の振り分け」に、保留の理由と書式（フォント・サイズ・色）ごとのまとまりが並びます。まとまりごとに「確定・申し送り・対象外」を押すと、一括で振り分けます。「保留すべて」でまとめて振り分けることもできます。「保留のある用語だけ表示」で、結果表を保留のある用語に絞り込めます。
   - 1ページずつ：目視確認で用語を開くと、保留のページがオレンジ色で強調されます。「確定・申し送り・対象外」を押して決めます。決め直したいときは「保留」に戻せます。
5. 保存すると、振り分けた内容がリストの列に入り、何をどう直したかが「訂正箇所」の列に入ります。振り分けていない保留は「保留」の列に残ります。

**保留になるページ**

| 保留の理由 | 意味 | 振り分けるまでの書き込み先 |
|---|---|---|
| リストになし | PDFで見つかったが、リストに書かれていないページ（不足の可能性） | 保留の列だけ |
| リストになし・複合語「…」 | 複合語の一部として見つかったが、リストに書かれていないページ | 保留の列だけ |
| PDFで見つからない | リストに書かれているが、PDFに語が見つからない、またはそのページがないページ（誤りの可能性） | 元の列＋保留の列 |
| アプリでは対象外 | リストに書かれているが、検索の設定（検索するページ・フォントなど）で外れたページ | 元の列＋保留の列 |

- PDFにないページ（例：p.99）は、ページ一覧で「該当なし」と表示されます。押すと、そのページの扱いだけを決められます。リストの誤りなら「対象外」、残すなら「確定」を押してください。
- リストの対象外の列に書かれているページは、保留にしません。
- 保留の列には「16（リストになし）、99（PDFで見つからない）」のように、ページと理由を書きます。
- 突合せ確認をオフにすると、リストに書かれたページを使わず、アプリの判定で転記します（このとき、リストとの違いは「訂正箇所」に記録されます）。

**訂正箇所の書き方**

読み込んだ時点のリストと比べて、変えた内容を短くまとめます。2回目以降の作業でも、最初に読み込んだリストからの変更をまとめて書きます。

- 「確定に追加：p.14, 15, 16」
- 「確定→対象外：p.99」
- 「申し送りに追加：p.14」
- 「用語「大西洋」→「西洋」」「用語を追加」

## AI校正（ローカルLLM、任意）

パソコンで動くAI（LM Studio、Ollama、llama.cpp、KoboldCpp、Jan など、OpenAI互換のサーバー）に、各ページの前後の文を読ませて、索引に載せるべきかを判定させます。

**準備**

- **LM Studio**：「Developer」でサーバーを起動し、「Enable CORS」をオンにします。
- **Ollama**：環境変数 `OLLAMA_ORIGINS` に `*` を設定して、Ollamaを起動し直します。

**使い方**

1. 左の「6 AI校正」で「自動で探す」を押し、モデルを選びます。
2. 「要確認の用語を確認」または「すべての用語を確認」を押します。
3. アプリの判定とAIの判定が違う箇所は、提案として表示されます。
   - 結果表の「AI」列
   - 目視確認のページ一覧の「AI」の印
   - 判定理由の欄
4. 提案は「AIの提案を反映」を押すまで、結果には反映されません。

**作業指示に従って自動で振り分ける**

教科書の作り方は本ごとに違うため、アプリの判定だけでは決めきれない場合があります。そのときは、作業指示をAIに読ませて振り分けさせます。

1. 検索してから、「AIへの作業指示」に指示文を貼り付けます。
   - 例：「本文中の太字の語だけを拾う。見出し・図表の説明文・側注での出現は対象外。」
2. 必要なら「対象」を選び（すべての用語／要確認の用語だけ／選択中の用語だけ）、「作業指示を実行」を押します。
3. AIは、各ページの用例に次の書式情報を合わせて読み、指示に照らして「確定」「申し送り」「対象外」に振り分けます。
   - 前後の文
   - フォント名、ゴシック／明朝、太字かどうか
   - 文字サイズ（本文より大きい・同じ・小さい）
   - 色（文字色を解析した場合）
   - 複合語かどうか
4. 結果は「AIの提案」と違い、その場で反映されます。判定が変わったページは、備考に理由が記録されます。例：「p.15は作業指示に基づきAIが要確認と判定（側注での出現）。拾う場合、p.15追加。」「対象外：p.12（作業指示に基づきAIが対象外と判定：見出しでの出現）」

**振り分けの注意点**

- 目視確認で手動で決めたページと、自分で追加したページは、AIの判定で上書きしません。
- 指示文は、保存時の「さくいん拾い_設定」シートに記録され、復元できます。
- 指示が触れていないページは、いまの判定のまま変えません。指示に当てはまるか判断がつかないページは「申し送り」になります。
- 結果表の「AI」列には「指示で3件」（判定が変わったページ数）または「指示どおり」と表示されます。

**注意点**

- 1回の問い合わせに180秒以上かかった場合は、その用語をエラーとして次の用語に進みます。
- 判定の精度はモデルによって大きく変わります。小さなモデルでは、回答の形式が崩れてエラーになることがあります。

## パネルの切り離し

「設定」「結果」「目視確認」の各パネルの見出しにある「別ウィンドウ」を押すと、そのパネルを独立したウィンドウに表示できます。

- ウィンドウを閉じるか「ここに戻す」を押すと、元の位置に戻ります。
- パネルの境目はドラッグで幅を変えられます。ダブルクリックで元の幅に戻ります。

**注意点**

- ブラウザがポップアップをブロックしている場合は、このファイルのポップアップを許可してください。
- 設定パネルを別ウィンドウにしているとき、ノンブル・検索範囲の指定画面は元のウィンドウ側に開きます。
- 別ウィンドウに移した設定パネルでは、フォント一覧の見本がPDFの書体ではなく通常の書体で表示されます。

## 知っておいてほしいこと（検索の仕組みと限界）

- 改行や行の折り返しはつなげて検索します。行をまたいだ語も見つかります。
- 全角／半角の英数字・記号・括弧、半角カナは同じ文字として扱います（例：「ＤＮＡ」「（１）」「ﾃﾞｰﾀ」は「DNA」「(1)」「データ」で見つかります）。
- 英字の大文字・小文字は区別しません（「dna」も「DNA」で見つかります）。
- ルビ付きの語は、ルビ（ふりがな）を除いて検索します。PDFの中で「日にち露ろ戦争」のようにルビが混ざっていても、「日露戦争」で見つかります。
  - ルビは、①ページ全体の文字より十分小さいかなか、②漢字のすぐ上（縦組みでは右）に乗っている、その漢字より小さいかなのどちらかで見分けます。②により、大見出し・小見出しのルビも見分けます。
  - 拾い漏れを防ぐため、ルビとして除いた文字の中にだけ用語が見つかった場合は、黙って外さず申し送りにします（備考に「ルビ（ふりがな）と判定した文字に一致。」と書きます）。
- 地図の「地　中　海」のように字間を空けた語や、1字ずつ置かれた語も、つなげて検索します（縦に並んだ文字も同じです）。
- 地図などで文字が1字ずつ別々に置かれ、PDFの中での文字の並び順がばらばらな場合は、「5 検索の設定」の「1字ずつ置かれた文字（地図など）を、位置と書式からつなげて検索する」をオンにします（初期設定はオフ）。
  - 同じフォント・同じ大きさ・同じ色で、横または縦に一列に並んだ短い文字だけをつなげます。字間が急に広がるところでは切ります。
  - 関係ない語をつなげて誤って拾うことがあるため、目視確認と合わせて使ってください。
- 大きさや位置の違う文字をまたいで一致した箇所は、確定にせず申し送りにします。備考には「離れた文字（大きさや位置が違う文字）をまたいで一致。」と書きます。見出しと本文、隣り合う地名などが偶然つながった場合を、確定にしないためです。
- 紙面に表示されない文字（透明テキスト）は、初期設定では検索しません。PDFを読み込むと、透明テキストの字数を判定欄に表示します。「5 検索の設定」の「見えない文字（透明テキスト）を除いて検索する」をオフにすると検索します。
- 白い文字は、色の付いた背景の上に置かれることもあるため、見えない文字としては扱いません。白地に白い文字などを外したいときは、「文字色を解析」してから文字色で絞り込んでください。
- 「・」「＝」「―」「-」などの区切り記号は無視して照らし合わせます（「アジア―アフリカ会議」「アジア＝アフリカ会議」「アジア・アフリカ会議」は同じ語として見つかります）。
- 語の最後の長音「ー」の有無は区別しません（「ガンディ」と「ガンディー」、「コンピュータ」と「コンピューター」）。
- 半角・全角のスペースが間に入っていても見つかります（「ABCD 包囲網」も「ABCD包囲網」で見つかります）。
- 括弧の付いた用語は、括弧内を除いた語で検索します。さらに括弧の中身によって、次のようにも探します。
  - 括弧内が英字の略称（例：「アジア―アフリカ（AA）会議」）：略称の書き方「AA会議」でも検索し、確定にします。
  - 括弧内が名前など（例：「ガンディ（インディラ）」）：「ガンディ」と「インディラ」の両方で検索し、どちらで見つかったページも確定にします。「インディラ」だけで拾ったページは、備考に「p.202は括弧内の「インディラ」の表記で拾った。」と書きます。
  - 同じ語の用語がリストにほかにもある場合（例：「ガンディ」と「ガンディ（インディラ）」）は、それぞれに分けて転記します。
    - 「インディラ＝ガンディー」「ガンディー（インディラ）」のように、括弧内の語と並んで出てくる箇所は「ガンディ（インディラ）」の確定、「ガンディ」の申し送りにします。
    - そのページのほかの「ガンディー」も、同じ人物とみなして「ガンディ（インディラ）」の確定にします。
    - 括弧内の語と並んだ表記がないページは「ガンディ」の確定、「ガンディ（インディラ）」の申し送りにします。
    - 両方の人物が出てくるページは、両方の確定になることがあります。
- 部首用の文字コードで書き出された漢字（「⻄」など）は、通常の漢字に直して検索します。
- 表記ゆれは自動では吸収しません。漢字とかな、旧字体、送り仮名の違いなどです。「見つからず」になった語は表記を確認してください。
- 図版の中の文字（画像）や、アウトライン化された文字は検索できません。
- 縦書きの本でも検索とノンブルの読み取りはできますが、強調枠の位置は横組みほど正確ではありません。
- 改行をまたいだ語も検索します。ただし複合語かどうかの判定では、次の改行を語の切れ目として扱います。
  - 前の行が次の行より明らかに短いとき（見出し・囲み・段落の終わりなど）
  - 改行の前後で文字の大きさが変わるとき
  - 行末まで文字が詰まった行で改行している場合は、語の途中で折り返した可能性があるため、つながった語として扱います。
- 複合語の判定は「前後に漢字かカタカナが続くか」で行っています。漢字とカタカナはつながった語として見ます（「インド洋」「東インド会社」「インド航路」「ロシア革命」は、「インド」「革命」の複合語として申し送りになります）。
  - 人名などの後ろに付く肩書き（首相・大統領・国王・皇帝・将軍・博士・氏など）は複合語にしません（「ガンディー首相」は「ガンディー」として確定）。肩書きの一覧はアプリ内の設定（titleSuffixes）にあります。
  - 地図の「イ　ン　ド　洋」のように1字ずつ間を空けた語も、同じ行の中なら間を詰めて判定します。
  - リストに長い方の用語（例：「インド洋」）もあるときは、その箇所は長い方の用語の確定になり、短い方（「インド」）には入れません。

## 困ったとき

| 症状 | 確認すること |
|---|---|
| 予想抽出精度が「低」、または見本の文字が化けている | PDFの書き出し設定（フォントの埋め込み・文字情報）を確認し、PDFを書き出し直してください。 |
| ノンブルが読み取れない、番号がずれる | 枠がノンブルの数字だけを囲んでいるか、「PDFの1枚目」の左右の設定が正しいかを確認してください。 |
| 「ノンブルが1ページも読み取れていません」と出る | 枠の位置が数字から外れています。位置を指定し直してください。 |
| 柱の語が全ページで拾われる | 「検索範囲を指定」で本文だけを囲んでください。 |
| 索引ページの語が拾われる | 「検索するページ」で本文の範囲だけを指定してください。 |
| 「検索中に設定が変わったため、検索を中止しました」と出る | 検索中に設定を変えると、結果の取り違えを防ぐために検索を中止します。もう一度「検索して転記」を押してください。 |
| 太字のはずの語が対象外になる | 強調箇所をクリックし、メニューに表示されるフォント名と対象外の理由を確認してください。「検索対象のフォントに加える」で、その場で対象にできます。名前にBoldが付かないフォントの場合は、「本文以外」のボタンも試してください。 |
| 同じファイルを読み込み直したい | そのままもう一度選ぶかドロップすれば、読み込み直します。 |
| ドロップしても読み込まれない | 処理中（上部のバーが動いている間）は読み込みません。終わってからドロップしてください。PDFとExcel（.xlsx）以外のファイルは読み込めません。 |
| 検索で拾われないページを索引に入れたい | 目視確認でそのページを開き、「文字をドラッグして追加」で本文の文字を囲んでください。 |
| リストの用語の表記が間違っている | 結果表で用語を選び、目視確認の「用語を直す」で直してください。直した内容は「訂正箇所」に残ります。 |
| 前回の続きにならない | 前回と同じPDFか確認してください。ページ数などが違うと自動では復元しません。また「さくいん拾い_設定」シートを消したExcelでは、設定を引き継げません。 |
| 保存ボタンが押せない | 列の指定が重複していないか、用語の列と同じ列を指定していないかを確認してください。 |
| 別ウィンドウが開かない | ブラウザのポップアップの許可を確認してください。 |
| AIに接続できない | AIサーバーの起動、CORSの設定、サーバーURLを確認してください。 |

## 保存される設定

次の設定はブラウザに記憶され、次に開いたときもそのまま使えます。

- パネルの幅
- 目視確認の単ページ／見開き
- 強調の色
- AIサーバーのURLとモデル
- AIへの作業指示

保存していない作業があるときにブラウザのタブやウィンドウを閉じようとすると、本当に閉じてよいか確認します。作業中の処理（読み込み・検索・AIなど）があるときも同じです。

ブラウザのサイトデータを消去すると、初期設定に戻ります。
